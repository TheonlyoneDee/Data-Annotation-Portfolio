# Quality Assurance Report – Project 4

## Project
Image Annotation – Object Detection

## Annotation Tool
Label Studio

## Annotation Format
COCO with Images

## Quality Checks Performed

The annotated dataset was reviewed for the following:

1. **Label Accuracy:** Checked that objects were assigned to the correct categories.
2. **Bounding Box Accuracy:** Reviewed box placement to ensure objects were properly enclosed.
3. **Consistency:** Checked that the same annotation rules were applied across images.
4. **Object Identification:** Avoided annotating objects whose identities were unclear.
5. **Category Compliance:** Ensured that only the five approved object categories were annotated.

## Approved Labels
- Person
- Car
- Bicycle
- Dog
- Backpack

## Outcome
The dataset was reviewed for annotation consistency and exported in COCO format with images.

## Conclusion
The quality assurance process helped maintain consistent object labels and bounding-box annotations throughout the dataset.
