# Project 4: Image Annotation – Object Detection

## Project Overview
This project focuses on image annotation for object detection using bounding boxes. The objective was to identify and label objects within images to create a structured dataset suitable for machine learning applications.

## Objective
To develop practical image annotation skills by identifying objects, assigning the correct labels, and drawing accurate bounding boxes around them.

## Tools Used
- Label Studio
- COCO Annotation Format
- GitHub

## Annotation Type
Object Detection – Bounding Box Annotation.

## Annotation Labels
The project uses the following object categories:
- Person
- Car
- Bicycle
- Dog
- Backpack

## Annotation Process
1. Selected images for annotation.
2. Created the object detection labels.
3. Identified objects belonging to the defined categories.
4. Drew bounding boxes around identifiable objects.
5. Reviewed annotations for consistency.
6. Exported the completed dataset in COCO format with images.

## Dataset Format
COCO with Images.

## Quality Control
Annotations were reviewed to check:
- Correct object classification.
- Bounding-box placement.
- Consistency in label usage.
- Avoidance of unsupported or uncertain labels.

## Project Outcome
A structured image dataset containing object detection annotations and corresponding images, exported in COCO format.

## Portfolio Purpose
This project demonstrates practical experience with image annotation, object detection, bounding-box labeling, dataset organization, and quality control.
