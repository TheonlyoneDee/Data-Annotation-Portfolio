# Image Annotation Guidelines

## Annotation Task
Object detection using bounding boxes.

## Labels
The following five object categories were used:

- Person
- Car
- Bicycle
- Dog
- Backpack

## Annotation Rules

1. Draw a bounding box around each identifiable object belonging to the approved categories.
2. Ensure boxes cover the visible extent of the object as accurately as possible.
3. Assign the correct label to each object.
4. Annotate partially visible objects only when their identity is clear.
5. Do not annotate objects outside the approved label categories.
6. Avoid guessing when an object is too blurry or unclear.
7. Maintain consistent annotation practices across all images.

## Quality Control

Annotations were reviewed for:
- Correct labels.
- Accurate bounding-box placement.
- Consistent application of annotation rules.
- Missing or incorrectly labelled objects.

## Annotation Format
COCO with Images.
