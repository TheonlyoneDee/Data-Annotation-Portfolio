# Quality Assurance Report – Project 5

## Project
Video Annotation – Pedestrian Detection and Tracking

## Annotation Tool
Label Studio

## Video Specifications
- Duration: 20 seconds
- Resolution: 4K

## Annotation Category
Person

## Quality Checks

The annotation work was reviewed based on the following criteria:

1. **Pedestrian Identification:** Checked that clearly identifiable pedestrians were correctly identified.
2. **Bounding Box Accuracy:** Reviewed box placement to ensure pedestrians were properly enclosed.
3. **Tracking Consistency:** Checked that tracking identities remained consistent as pedestrians moved through the video.
4. **Duplicate Tracking:** Reviewed annotations for unnecessary duplicate identities.
5. **Label Consistency:** Ensured the approved Person category was used consistently.

## Export Format
JSON (Label Studio annotation export).

## Outcome
The video annotation task was completed and the annotation data was exported in JSON format.

## Conclusion
The quality assurance process focused on maintaining consistent pedestrian identification, accurate bounding-box placement, and reliable tracking identities throughout the video.
