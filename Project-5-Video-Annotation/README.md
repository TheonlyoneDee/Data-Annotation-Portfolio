# Project 5: Video Annotation – Pedestrian Detection and Tracking

## Project Overview

This project focuses on video annotation and pedestrian tracking using bounding boxes. The task involved identifying pedestrians in a video, annotating their visible bodies, and maintaining consistent tracking identities as they moved across video frames.

## Project Objective

To develop practical video annotation skills, including pedestrian detection, bounding-box placement, and multi-object tracking.

## Tools Used
- Label Studio
- GitHub

## Video Specifications
- Video Duration: 20 seconds
- Video Resolution: 4K
- Annotation Type: Video Object Detection and Tracking

## Annotation Category

The project uses one object category:

- **Person:** Any clearly identifiable human pedestrian.

## Annotation Methodology

1. Reviewed the video before annotation.
2. Identified pedestrians appearing in the footage.
3. Drew bounding boxes around visible pedestrians.
4. Assigned tracking identities to individual pedestrians.
5. Maintained tracking identities across video frames.
6. Reviewed annotations for consistency.

## Annotation Guidelines

- Annotate clearly identifiable pedestrians.
- Use accurate bounding boxes.
- Maintain consistent tracking IDs.
- Avoid duplicate tracking identities.
- Do not annotate people appearing on posters, billboards, or screens.
- Avoid guessing when a person is unclear.

## Export Format

JSON (Label Studio annotation export).

## Quality Assurance

The annotation process focused on:
- Correct pedestrian identification.
- Bounding-box accuracy.
- Consistent object tracking.
- Proper use of annotation labels.
- Avoidance of duplicate annotations.

## Project Outcome

A video annotation dataset containing pedestrian annotations and tracking information, exported in JSON format.
