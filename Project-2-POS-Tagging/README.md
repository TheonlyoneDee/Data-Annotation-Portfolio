# Project 2: Part-of-Speech (POS) Tagging

## Project Summary

This project focuses on Part-of-Speech (POS) tagging, a text annotation task that involves identifying and assigning grammatical categories to words based on their functions within sentences.

The project involved annotating 50 English sentences using the Universal Dependencies Part-of-Speech (UPOS) tag set. The annotation process was carried out using Doccano.

## Project Objectives

- Practise word-level text annotation.
- Identify grammatical categories within different sentence structures.
- Apply the UPOS tagging system consistently.
- Produce a structured and annotated dataset in JSONL format.
- Perform quality checks on completed annotations.

## UPOS Labels Used

The project uses 17 UPOS labels:

ADJ, ADP, ADV, AUX, CCONJ, DET, INTJ, NOUN, NUM, PART, PRON, PROPN, PUNCT, SCONJ, SYM, VERB, X.
