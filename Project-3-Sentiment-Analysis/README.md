# Project 3: Sentiment Analysis

## Project Overview

This project demonstrates document-level sentiment classification using natural language processing (NLP) annotation techniques.

The objective is to classify written text according to the sentiment expressed by the author, using three predefined categories: Positive, Negative, and Neutral.

The dataset consists of 50 text samples covering different real-world contexts, including product reviews, customer experiences, restaurant services, online shopping, and general feedback.

## Project Objectives

- Develop practical experience in text classification.
- Identify positive, negative, and neutral sentiments.
- Apply consistent annotation guidelines.
- Handle ambiguous and mixed-sentiment expressions.
- Perform quality assurance on annotated data.
- Produce a structured dataset suitable for NLP applications.

## Annotation Methodology

The project uses document-level text classification.

Each complete text is assigned one sentiment label based on its overall meaning.

### Annotation Labels

| Label | Description |
|---|---|
| Positive | Expresses satisfaction, approval, happiness, or favourable opinions. |
| Negative | Expresses dissatisfaction, disappointment, criticism, or unfavourable opinions. |
| Neutral | Presents factual information without a clearly expressed positive or negative sentiment. |

## Annotation Challenges

The dataset includes examples involving:

- Mixed sentiments.
- Sarcasm and implied criticism.
- Ambiguous expressions.
- Factual statements.
- Context-dependent sentiment.

These examples help demonstrate the importance of context and consistent annotation decisions.

## Quality Assurance

The annotated dataset underwent a review process covering:

- Missing text and labels.
- Label consistency.
- One-label-per-document validation.
- Comparison against prepared reference annotations.
- Review of ambiguous and challenging examples.

The reference comparison showed agreement across all 50 samples. This is an internal comparison, not an independent inter-annotator agreement measurement.
