## 📁Projects

### 1. Named Entity Recognition (NER)

**Objective:** Identify and classify named entities within text.

- Annotation categories: Person, Organization, Location.
- Tool: Doccano
- Task type: Text annotation / Sequence labeling.
- Skills: Entity identification, span annotation, and label consistency.

[View Project 1](./Project-1-NER/)

---

### 2. Part-of-Speech (POS) Tagging

**Objective:** Identify and classify words according to their grammatical roles in sentences.

- Annotation approach: Universal POS (UPOS) tagging.
- Tool: Doccano
- Task type: Sequence labeling.
- Skills: Grammatical classification, token annotation, and consistency checks.

[View Project 2](./Project-2-POS-Tagging/)

---

### 3. Sentiment Analysis

**Objective:** Classify text samples according to the sentiment they express.

- Dataset size: 50 text samples.
- Annotation categories: Positive, Negative, Neutral.
- Tool: Doccano
- Dataset format: JSONL.
- Skills: Sentiment classification, text labeling, and quality checks.

[View Project 3](./Project-3-Sentiment-Analysis/)

---

### 4. Image Annotation (Object Detection)

**Objective:** Identify objects in images and annotate them using bounding boxes.

- Annotation categories: Person, Car, Bicycle, Dog, Backpack.
- Tool: Label Studio.
- Export format: COCO.
- Skills: Object detection, bounding box annotation, and image labeling.

[View Project 4](./Project-4-Image-Annotation/)

---

### 5. Video Annotation (Pedestrian Detection and Tracking)

**Objective:** Annotate pedestrians in video footage and maintain consistent tracking IDs.

- Video duration: 20 seconds.
- Resolution: 4K.
- Annotation category: Person.
- Tool: Label Studio.
- Export format: JSON.
- Skills: Video annotation, pedestrian detection, bounding boxes, and object tracking.

[View Project 5](./Project-5-Video-Annotation/)
